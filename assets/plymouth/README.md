# Plymouth Boot Splash Assets & Specs

This directory houses the Plymouth boot splash configuration for Kushagra OS.

## Files
1. `kushagra.plymouth`: Theme descriptor file (maps to `/usr/share/plymouth/themes/kushagra/kushagra.plymouth`).
2. `kushagra-logo.png`: Centered boot splash icon (recommended: 256x256 or 512x512 transparent PNG).
3. `progress-bar.png` (optional): For two-step/progress boot splash.
