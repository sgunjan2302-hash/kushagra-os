# Kushagra OS Wallpapers

Place default wallpapers here to be included in the image build:

- `kushagra-default-light.png`: 3840x2160 (4K UHD) sRGB PNG
- `kushagra-default-dark.png`: 3840x2160 (4K UHD) sRGB PNG

These will be installed to `/usr/share/wallpapers/Kushagra/` on the target system and linked to KDE Plasma's default desktop background configuration.
